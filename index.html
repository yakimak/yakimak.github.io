HTTP-сервер поверх TCP (реализация на Python)

📌 Как запустить и продемонстрировать (чтобы увидеть 200, 404 и 403):
1️⃣ Скачайте simple_http_server.py (кнопка ниже).
2️⃣ Убедитесь, что установлен Python 3.6+.
3️⃣ Запустите в терминале: python simple_http_server.py
4️⃣ Сервер создаст папку www с двумя файлами: index.html и page2.html.
5️⃣ Откройте браузер и последовательно перейдите по адресам:
  • http://localhost:8080/ → главная страница (200 OK)
  • http://localhost:8080/page2.html → вторая страница (200 OK)
  • http://localhost:8080/notexist.html → ошибка 404 Not Found
  • http://localhost:8080/../secret.txt → ошибка 403 Forbidden (попытка выйти из корня)
