# Волчонок Тимка 🐺

Игра-тамагочи в духе «Мой говорящий Том»: четыре комнаты, забота о волчонке и десять мини-игр.
Вся графика рисуется кодом на Canvas — никаких внешних картинок и библиотек.

## Как запустить

- **Самый простой способ:** откройте `index.html` двойным щелчком в Chrome, Edge или Яндекс.Браузере.
- Или запустите `start-game.bat`.
- Или поднимите локальный сервер:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000

## Что можно делать

| Комната | Занятия |
|---|---|
| 🛋️ Зал | Погладить, поговорить, включить телевизор, играть в мини-игры |
| 🍳 Кухня | Покормить (каша бесплатно, мясо, яблоко и пирожное — за монетки) |
| 🚽 Ванная | Отвести в туалет, помыться |
| 🛏️ Спальня | Уложить спать / разбудить, включить ночник |

- **Клик по Тимке** — погладить (растёт настроение).
- **Клик по предметам** — взаимодействие: миска, холодильник, кровать, ночник, унитаз, ванна, телевизор. При наведении появляется подсказка.
- Следи за шкалами: **Сытость**, **Энергия**, **Чистота**, **Туалет** и **Настроение**. Если «Туалет» опустеет, волчонок расстроится.
- Волчонок сам разговаривает, следит за курсором, моргает, виляет хвостом и реагирует на ласку.
- Прогресс сохраняется автоматически в браузере. Кнопка **↺** начинает всё заново.
- Звук отключается кнопкой **🔊**.

## Десять мини-игр

1. 🦴 **Костяная лихорадка** — лови кости в корзинку и уворачивайся от бомб.
2. 🫧 **Охота на пузыри** — лопай пузыри, золотые дают больше очков.
3. 🃏 **Найди пару** — открой все одинаковые карточки.
4. 🎣 **Рыбалка на закате** — останови поплавок в зелёной зоне.
5. 🏃 **Лесной забег** — прыгай через пни и собирай ягоды.
6. 🔨 **Крот-шалун** — стучи по кротам, не трогай бомбы.
7. 🐍 **Змейка-волчонок** — собирай ягоды и не кусай себя за хвост.
8. 🧩 **Пазл с Тимкой** — собери портрет волчонка.
9. 🎈 **Воздушный тир** — лопай шарики и держи серию.
10. 🎵 **Повтори за Тимкой** — запомни и повтори мелодию.

За игры дают монетки и настроение. Рекорды сохраняются.

## Управление

- Мышь / палец — всё взаимодействие.
- В мини-играх также работают стрелки, WASD, пробел и свайпы.
- `1`–`4` — быстрый переход между комнатами, `P` — погладить, `G` — мини-игры.

## Технически

```
index.html          — разметка и подключение скриптов
css/style.css       — оформление интерфейса
js/util.js          — утилиты, рисование, синтезированный звук
js/save.js          — состояние и сохранение
js/wolf.js          — волчонок (позы, эмоции, анимации)
js/rooms.js         — четыре комнаты и предметы
js/minigames.js     — каркас мини-игр
js/mg-*.js          — десять мини-игр
js/game.js          — игровой цикл, статы, действия, интерфейс
```

Чистый HTML + CSS + JavaScript (ES2017), Canvas 2D, Web Audio API. Работает офлайн.
